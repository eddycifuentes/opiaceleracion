## 💾 Cómo Funciona

- **Frontend**: React 18 + TypeScript
- **Estado**: Zustand (en memoria)
- **Datos**: Mock data realista
- **Estilos**: Tailwind CSS
- **Gráficos**: Recharts
- **Iconos**: Lucide React
- **Router**: React Router v6 (hash-based)
