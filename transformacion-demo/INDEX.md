## 📊 Información Rápida

### Estadísticas
- **23 archivos TypeScript**
- **10 componentes reutilizables**
- **4 stores Zustand**
- **6 páginas funcionales**
- **~3,500+ líneas de código**

### Tech Stack
- React 18 + TypeScript
- Tailwind CSS
- Zustand
- Recharts
- React Router v6
